# Learned Constraints (self-improvement loop)

Rules promoted from the correction ledger (`corrections/LEDGER.md`), kept in their own
file so the core `SKILL.md` doesn't grow unbounded (see `SELF_IMPROVEMENT.md` §
Placement duty — a new rule belongs here **only** when no existing SKILL.md section is
a better, more targeted home for it). Each rule is binding on future sessions until
superseded by a later entry citing its id.

Read this file at the start of every session alongside `SKILL.md`.

Empty until the first correction is promoted here (some corrections instead land as
targeted patches directly inside `SKILL.md`'s own sections — check there too, e.g.
`CORR-2026-08-14-001` lives in § 5's Delivery checklist).
